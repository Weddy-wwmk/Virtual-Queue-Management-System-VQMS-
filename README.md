Virtual Queue Management System (VQMS)

VQMS is a full-stack digital solution designed to streamline patient flow and eliminate physical waiting lines in busy medical centers, specifically built for hospital eye units.
Instead of crowded waiting rooms, the system digitizes the entire queuing lifecycle, from arrival to treatment, while keeping patients updated in real time.

💡 Key Functionality
Smart Triaging: Staff can digitally log incoming patients and assign them to specific lines based on their medical needs.
Live Updates: Tracks patient progression through distinct stages (Triage --> Doctor).
Twilio WhatsApp Alerts: Automatically sends real-time text messages to patients' phones as their appointment queue position nears, allowing them to wait comfortably anywhere.
Role-Based Views: Tailored dashboards for Administrators, Triage Nurses, and Doctors to manage workflows smoothly.

🛠️ Tech Stack
Frontend: React.js (User Interface)
Backend: Python / Flask (REST API & Logic)
Database: MySQL (Queue & Patient Tracking)
Communications: Twilio WhatsApp Business API
